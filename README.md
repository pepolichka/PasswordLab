# 🔐 PasswordLab

**PasswordLab** — это клиентское веб-приложение для генерации и проверки надёжности паролей.  
Проект выполнен в рамках курсовой работы по дисциплине *«Проектирование и разработка веб-приложений»*.

Приложение позволяет:
- генерировать безопасные пароли с заданными параметрами;
- проверять надёжность пользовательских паролей;
- получать рекомендации по усилению пароля;
- хранить историю генерации локально в браузере.

**Онлайн-версия (GitHub Pages):**  
https://pepolichka.github.io/PasswordLab/

---

##  Цель проекта

Целью проекта является разработка веб-приложения, демонстрирующего принципы:
- клиентской веб-разработки;
- базовой информационной безопасности;
- модульной архитектуры JavaScript-приложений;
- работы с пользовательскими данными без передачи на сервер.

---

##  Функциональные возможности

###  Генерация паролей
- настройка длины пароля;
- выбор наборов символов:
  - строчные буквы (a–z);
  - заглавные буквы (A–Z);
  - цифры (0–9);
  - специальные символы;
- исключение визуально похожих символов (O/0, I/1);
- режим генерации без повторов;
- использование `crypto.getRandomValues` для повышения криптостойкости.

###  Проверка пароля
- анализ длины пароля;
- проверка наличия разных типов символов;
- сравнение с базой популярных и небезопасных паролей;
- формирование списка рекомендаций.

###  Оценка надёжности
- расчёт силы пароля по 100-балльной шкале;
- визуальный индикатор уровня надёжности;
- классификация: слабый / средний / надёжный.

###  История генерации
- хранение последних 10 паролей;
- использование `localStorage`;
- маскирование паролей для повышения конфиденциальности;
- возможность очистки истории.

##  Архитектура проекта

Проект реализован по модульному принципу.  
Каждый JavaScript-файл отвечает за отдельную логическую часть приложения.


```text
PasswordLab/
 ├── index.html
 ├── assets/
 │   └── style.css
 ├── js/
 │   ├── app.js
 │   ├── matrix.js
 │   ├── generator.js
 │   ├── validator.js
 │   ├── strength.js
 │   ├── storage.js
 │   └── common-passwords.js
 ├── README.md
 ├── TESTCASES.md
 └── .gitignore
```

##  Используемые технологии

- **HTML5** — структура интерфейса  
- **CSS3** — стилизация, dark-theme интерфейс  
- **JavaScript (ES6+)** — логика приложения  
- **Canvas API** — анимированный фон  
- **Web Crypto API** — безопасная генерация случайных значений  
- **GitHub Pages** — публикация проекта  

---

##  Безопасность и конфиденциальность

- приложение не использует серверную часть;
- все вычисления выполняются на стороне клиента;
- введённые пароли никуда не передаются;
- история хранится только локально в браузере пользователя.
